# Comparative Mutational Signature Analysis of Lung Adenocarcinoma (LUAD) and Colorectal Adenocarcinoma (COAD)

## Overview

This project was carried out as part of my internship at **BiotechTrek**. The aim was to compare the mutational landscapes of Lung Adenocarcinoma (LUAD) and Colorectal Adenocarcinoma (COAD) using publicly available TCGA somatic mutation datasets. Mutation profiling and mutational signature analysis were performed using **maftools**, **SigProfilerMatrixGenerator**, and **SigProfilerExtractor**.

---

## Objectives

- Compare the mutational landscapes of LUAD and COAD.
- Identify frequently mutated genes.
- Generate mutation summary plots and oncoplots.
- Extract de novo SBS mutational signatures.
- Match extracted signatures to COSMIC SBS reference signatures.
- Compare mutational signatures between the two cancer types.
- Interpret the biological significance of the identified signatures.

---

## Dataset

- **Source:** The Cancer Genome Atlas (TCGA)
- **Cancer Types:**
  - Lung Adenocarcinoma (LUAD)
  - Colorectal Adenocarcinoma (COAD)
- **Reference Genome:** GRCh38
- **Mutation Data Format:** MAF (Mutation Annotation Format)
